1. 모든 태그는 <>로 감싼다.
2. 시작태그와 종료태그가 있다. <h1></h1>
3. 시작태그와 종료태그가 함께 있는 것도 있다. <br />
4. 태그 종류
- 제목 태그 : h1 ~ h6
- 웹페이지의 제목 : title
- 단락구분 : p
- 한줄 띄우기 : br
- 이미지 : img
- 링크 : a
- 강조 : strong , - 이탤릭 : em
- 페이지 줄 긋기 : hr
- 목록 : 번호 (ol - ordered list), 불릿 (ul - unordered list)
- 목록 안의 리스트 : li (list)
****
- div : 구역을 나누는 태그(의미없는 영역 잡는 데 사용) - 블럭요소
- span : 의미 없는 작은 상자 - 자기 크기 만큼만 잡힌다.(인라인요소)

=======================
- 블럭요소 : div, p, h1~h6, ul, li, form
- 인라인요소 : span, a, strong, em, img

=======================
- 시멘틱 태그 : div 태그인데 의미만 갖는 태그
- 종류 : header, footer, main, article, nav

========================
- HTML 구조를 빠르게 만드는 법
! : html 뼈대
. : class
# : id
> : 자식
+ : 형제
* : 반복
{} : 안에 들어갈 글자
$ : 번호
^ : 옆집
[] : 속성
